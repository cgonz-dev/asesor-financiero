# @copiloto/domain

Paquete independiente de frameworks para vocabulario y reglas puras de dominio. Fase 2 incorpora
estados internos, roles/capabilities de Household, la membresía Owner inicial, la forma conceptual
de una identidad externa ya verificada y la policy de lectura para `Private`, `SelectedMembers` y
`Household`. No contiene Prisma, NestJS, Auth0, Expo, persistencia de recursos ni reglas financieras.
